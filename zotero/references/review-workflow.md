# 多篇比较、综述与补充检索

1. 获取用户的研究问题、比较维度、阅读重点和未决问题，保存为可切换的 research-profile。不要求使用者先认识经典论文；缺少基础时将基础知识与方法谱系列为需要补查的内容。
2. 先对用户指定的分类/标签/检索结果进行单篇阅读。通过 `read list` 选择对应 job，不根据题录齐全程度冒充论文质量排名。`review prepare --jobs <ids...> --profile <name> --out corpus.json` 收集有原文依据的分析，返回缺失覆盖。旧 PDF 已变化时重新读取。
3. 宿主当前模型读取 corpus.json，组织跨论文比较：研究问题、方法/输入输出、数据及划分、训练与推理要求、指标和结果、消融、复杂度、复现条件、局限。维度按使用者问题调整，不把脑电等某个领域写成通用默认。
4. 梳理发展时区分明确引用的继承关系与模型解释的相似性。研究空白只列为假设，说明所读材料、检索范围、反例和需要验证的证据，不能用局部语料的未出现组合证明全球空白。
5. 阅读优先级默认考虑课题关联度、方法创新、可学懂和可实践的价值；先根据全文给出理由，期刊和引用量仅作背景信号。无法获取全文的候选明确标为题录/摘要层面，不与精读结果混同。
6. 要求逐项对比时优先使用 `review matrix prepare/render`，按研究问题选择列，保留“未报告”和“不可直接比较”。从已知论文追踪基础与后续工作时用有界的 `review discover`，引用关系不等于支持/反驳。二者的结构与限制见 [focused-reading.md](focused-reading.md)，无需加载完整翻译协议。

模型写出：

```json
{
  "fingerprint": "corpus.json中的指纹",
  "comparisons": [{"kind":"synthesis", "statement":"比较结论与适用条件（不能跨不兼容实验协议直接排精度）", "evidence":[{"job_id":"read-...", "claim_id":"p1-method-1"}]}],
  "development": [],
  "gaps": [{"kind":"hypothesis", "statement":"有待扩大检索和实验验证的研究假设", "evidence":[{"job_id":"read-...", "claim_id":"p2-limit-1"}]}],
  "reading_order": [],
  "limitations": ["具体缺少哪些数据、基线、实验协议或实现说明，以及为什么影响当前问题"],
  "search_queries": ["针对缺失证据的英文检索式", "针对基础方法或后续改进的检索式"]
}
```

执行 `review render --corpus corpus.json --input synthesis.json --out review.md`。脚本检查引用确实属于此语料，生成 Markdown，并自动用所给查询搜索 OpenAlex，将带推荐理由与证据层级的候选写入报告和 recommendations.json。新增候选尚未经过全文验证；把结果交给宿主模型按课题相关性、创新和可实践性进一步解释，不能把关键词命中当成已证明的创新。
准备后如果单篇阅读被修正，旧综述上下文会失效；重新 prepare 后再合成，避免继续使用已纠正的解释。

发现新的重要线索可继续 `review search --queries ... --profile ...`，或使用现有 find/import 命令。自动搜索不等于自动写库；推荐后按用户选择导入，再取得全文、建立阅读证据、更新综述。OpenAlex 出错或返回空结果时说明可能是网络或覆盖不足，不能当成“没有相关研究”。

示例课题（仅供测试，不是默认）：运动想象 EEG；Transformer 与电极图卷积 GCN 双分支教师，动态融合后蒸馏到 EEGNet。可比较跨被试零标签、少量标注校准、无标签适应；检查目标被试信息泄漏，区分每被试固定权重和每样本门控，以及学生部署时是否仍依赖教师。所有这些是待研究维度，不能假定方案已经有效。
